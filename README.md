# Home Assistant AI Tools

![项目图标](custom_components/ha_ai_tools/brand/icon.png)

通过独立配置的 DeepSeek、OpenAI、Azure 或本地兼容模型，结合 Home Assistant 语音设备创建提醒、自动化，查询天气，并保留连续对话与永久记忆。界面为中文，业务时间统一为北京时间 `Asia/Shanghai`。

## 功能

- 本地语音：独立识别/合成配置页、中文男女声试听、设备提醒音色、流水线差异预览和恢复点。Mac 服务单独安装，见 [部署说明](local_speech/README.md)。
- 模型：多连接、多助手，独立客户端；可导入 Extended OpenAI Conversation 2.0.3 稳定版配置，运行时无需安装该集成。
- 高级函数：native、script、template、rest、scrape、composite、sqlite 七类，支持 tools 与旧 functions 协议。
- 图像：`ha_ai_tools.query_image` 支持多张远程或 `www` 图片，使用所选助手的视觉模型；`ha_ai_tools.change_config` 供管理员更新连接。

- 提醒：一次、每天、工作日、每周；重启恢复，可查看、取消，并修改待执行提醒的播报设备。已结束记录可单条删除或批量清理。
- 播报：每条提醒独立选择一台或多台设备，到时仅向该条提醒选择的设备并行发送。默认设备只用于预选，修改默认设置不会改变已有提醒。
- 自动化：创建后可在 HA 自动化页面编辑、停用。采用 HA 原生验证、文件锁和写入器。未加载成功的操作保留原 ID，可重试加载。
- 天气：设置“家”“公司”等名称与现有天气实体映射，查询实况、每日和小时预报；主来源失效时自动使用同地点备用来源，恢复后优先使用主来源，并显示实际来源。
- 上下文：同设备最近15分钟的新唤醒延续对话，保留近期12轮，旧内容压缩为摘要。
- 记忆：自动提取明确稳定的偏好，支持“记住”“更正”“忘记”，页面可管理。HA 本地保存，按需提供给所选模型。过滤明显的密码、密钥和临时状态，请勿口述凭据。

## 安装与使用

要求 Home Assistant **2026.10.2 或更高版本**，以及可用的 OpenAI 协议或 Azure 模型服务。支持可播报的 `assist_satellite` 实体，以及由音箱集成提供的文本播报 `text` 实体。语音识别与合成可保留现有引擎，或接入可选 Mac 本地服务。

### HACS

1. 打开 HACS，右上角菜单选择“自定义存储库”。
2. 添加 `https://github.com/q848899176/home-assistant-ai-tools`，类别选择 **Integration（集成）**。
3. 搜索 **Home Assistant AI Tools** 并下载，重启 Home Assistant。

[在 HACS 中打开本仓库](https://my.home-assistant.io/redirect/hacs_repository/?owner=q848899176&repository=home-assistant-ai-tools&category=integration)

HACS 自定义仓库安装不依赖默认商店收录；仓库可以安装并不代表已获 HACS 官方审核收录。

### 手动安装

从 [Releases](https://github.com/q848899176/home-assistant-ai-tools/releases) 下载 `ha_ai_tools.zip`，将 ZIP 内全部文件解压至 `/config/custom_components/ha_ai_tools/`，确保 `manifest.json` 位于该目录内，然后重启。

也可下载源码，将其中的 `custom_components/ha_ai_tools` 整个目录复制到 `/config/custom_components/`。

### 配置

1. 在“设置 → 设备与服务 → 添加集成”搜索 **Home Assistant AI Tools**。
2. 填写模型连接地址、密钥及模型；也可在“模型连接”页面预览并导入旧 EOC 2.0.3 配置。密钥仅保存到 HA 配置子条目，不会回显；编辑时留空表示保留。
3. 在“设置 → 语音助手”打开语音流水线，将对话代理选择为 **AI Tools**。本地语音先在新标签页保存连接，创建 Nabu 测试流水线，核对差异后应用；保留生产流水线方便回退。
4. 打开侧栏 **AI 工具**，选择默认播报设备并保存。测试区仅向明确选择的 Nabu 播报，不按默认设备群发。
5. 在“天气地点”设置名称与现有天气实体的映射；在“永久记忆”查看、修改或删除偏好。
6. “对话助手”中可分别设置连接、模型、提示词和函数 YAML；高级参数控制输出长度、采样、工具轮次、用户名及上下文阈值。不同助手隔离近期上下文，共享记忆继续遵守家庭/个人归属。

集成依赖当前语音流水线提供的识别文字；如识别错误，可在“语音识别”中测试并调整 STT。天气地点映射不会自动创建天气服务或按经纬度查询外部天气。

天气备用来源从 HA 现有天气集成的区域、跟随家庭位置或经纬度配置中识别，仅容许小幅坐标舍入误差。不能确认位置或已停用的来源不会自动使用；所有来源失效时明确报错，不使用其他地点或旧缓存替代。查询切换不会修改保存的主来源。

创建提醒时，“本条提醒的播报设备”会直接列出支持播报的设备，可为喝水、吃药等不同提醒分别勾选。已有待执行提醒点击“修改播报设备”即可调整。取消全部勾选会提示至少选择一台，不会偷偷退回默认设备。

已完成、已取消、失败或错过的记录显示“删除记录”；“清理历史”会批量删除这些已结束记录。两种操作均会先确认，删除后不可恢复。待执行和正在播报的提醒受后端保护，不会被历史清理删除。

示例：

- “明天上午九点提醒我交电费。”
- “明天九点提醒我喝水，只在 Nabu 播报。”
- “把喝水提醒改为只在 Nabu 播报。”
- “每天晚上十一点关闭客厅灯。”
- “家里明天会下雨吗？”
- “记住我喜欢简短回答。” → “以后详细一点。”
- “把它关掉。”（承接同设备近期明确提及的设备）

## 边界

- 自动化目前支持明确实体的结构化配置；模板、任意事件动作及标签/楼层等间接控制目标会被拒绝。设备必须已向 Assist 公开。
- “同时播报”采用并行触发，不保证不同厂商音箱音频完全同步。界面显示的是 HA 服务调用结果，实际声音需通过设备试听验收。
- 24小时内过期的一次提醒补发一次；重启时过期重复提醒跳到下一未来时刻。重启中断的播报不自动重播，避免重复。
- 匿名语音使用家庭共享记忆；有可信用户身份时使用个人记忆。不根据音箱位置推断说话人。
- 初次加载会导入已有 `input_text.jarvis_long_memory` 的非敏感内容一次，保留原辅助实体。旧短期辅助实体不转换为永久事实。
- HA Store 文件：`.storage/ha_ai_tools.<配置条目ID>`。备份 HA 时一并备份；管理页面仅管理员可访问。
- 语音状态独立保存在 `.storage/ha_ai_tools.speech.<配置条目ID>`，包含设备音色、测试会话和恢复点。降级前先结束测试、恢复流水线和设备音色，再删除未引用的语音连接。
- AI Tools 音色试听及使用自定义音色的提醒不写磁盘缓存；Assist 对话遵循 HA 现有全局缓存策略。当前候选提供完整 WAV，不宣称流式首声或变速。
- 以“请复述”“复述”“请描述”“描述一下”开头的请求仅允许天气、提醒和记忆查询，不执行设备、提醒、自动化或记忆修改；引用中的偏好不自动记忆。需要实际执行时请单独明确下达指令。
- 0.3.0 的现场使用者接受当前语音体验并跳过剩余完整指标测试；原音准确率及成对首声统计未完成，TTS 完整生成 P50 约 1.57 秒，略高于 1.5 秒目标。详见 [发布说明](RELEASE_NOTES.md)。

## 开发检查

使用 Python 3.14，执行 `python -m pip install -r requirements-test.txt` 后运行：

```sh
python -m pytest -q
ruff check custom_components tests
node --check custom_components/ha_ai_tools/frontend/panel.js
```

测试覆盖原业务、独立连接、多助手、七类执行器、两种工具协议、图像路径与权限边界。实机验收和本地测试分别记录；服务投递成功不代表现场声音已经试听。

## 数据与隐私

- 仓库和发行包只含程序、测试及通用文档，不含家庭配置、提醒、记忆、凭据或实机截图。
- 语音文字、相关上下文、记忆及工具结果会发送给您配置的模型提供方；使用云端模型时会离开 HA 主机。连接密钥只保存到 HA 配置子条目；页面不回显，业务 Store 不复制凭据。
- 提醒和记忆保存在 HA 本地 Store 中，建议变更前备份。删除历史和删除记忆均不可通过本集成恢复。
- 需要回退时，在语音流水线中选择原来的对话代理，再停用本集成；保留 Store 文件可保留本地数据。

## EOC 2.0.3 兼容与迁移

保留 `spec` / `function` YAML 格式及稳定版模型参数。native 支持 execute_service、execute_service_single、add_automation、get_history、get_energy、get_statistics、get_user_from_user_id。

升级已有版本时保留根配置条目和默认对话实体，提醒、地点、播报设备及永久记忆继续使用原 Store。原 EOC 配置作为回退保留。若自动导入失败，提醒照常调度，可在管理页检查后重试；不要删除原配置后再导入。

新事件使用 `ha_ai_tools.conversation.finished` 和 `automation_registered_via_ha_ai_tools`，保留对话响应/消息及自动化配置字段。引用旧服务或事件的自动化须按导入预览逐项调整，不自动批量改写。

高级函数由管理员配置。普通实体调用遵守 Assist 暴露及用户权限；动态脚本目标必须可预检。REST 地址限制在管理员配置的 origin；SQLite 数据库限制在 HA 配置目录且只读，Recorder 查询按公开实体过滤。无限调用、任意文件、管理域服务及越权读取不属于兼容范围。

图像问答仅管理员或可信 HA 自动化可调用；本地图片仅限 `/config/www` 或 `/local`，不跟随符号链接。最多10张静态 PNG/JPEG/GIF/WebP，每张10 MiB、合计20 MiB。图片会发送给所选模型；模型不支持视觉时返回明确错误。

“跳过认证”会明确不发送认证头，适用于匿名兼容服务；此选项与 EOC 的仅跳过认证预检语义不同。函数后台延迟任务会在集成卸载时取消；长任务请使用原生 HA 自动化。上游 MIT 来源声明见 [NOTICE](custom_components/ha_ai_tools/functions/NOTICE)。
